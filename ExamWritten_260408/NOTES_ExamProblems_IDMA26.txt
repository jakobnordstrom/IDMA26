1. INDUCTION PROOFS

(a) Prove that if x_1, x_2, ..., x_n are non-negative real numbers, then it holds that

(1 + x_1) (1 + x_2) \cdots  (1 + x_n) >= 1 + x_1 + x_2 + \cdots + x_n .

(b) Prove that every integer n >= 12 can be written as 4a + 5b for a and b non-negative integers.


2.COMBINATORICS

What is the largest positive integer n such that 26!/6^n is also an integer?


3. PSEUDOCODE

Algorithms for
- insertion in a doubly linked list
- removal in a doubly linked list
- lookup in a doubly linked list
- and a spoiler
and ask to match the code snippets to these alternatives (with explanations).
10 p for correct match, 10 p for brief explanation


4. LOGIC

Same type of problem as last year

(a) One tautology.

(b) One formula that can be made into tautology by negating a variable.

(b) Does going to the smallest child in a max-heap and finally returning a leaf always yield the smallest element? (No.)

7. STRONGLY CONNECTED COMPONENTS

Start with small directed graph on 6 vertices

(a) Say that the relation E(u,v) holds for two vertices u and v in the graph if there is a directed edge from u to v.
What is the the matrix representation of this relation

(b) Take reflexive closure.

(c) Then take transitive closure.

(d) Define new relation S(u,v) such at S(u,v) holds precisely when T(u,v) and T(v,u) holds.
This gives a particular type of relation that we discussed in class.
What is this type of relation called? Prove that we indeed get this type of relation.


8. TRICKY COMBINATORICS

Suppose that we have a universe of n elements and are interested in counting the number of multisets of size r.
Jakob has a new idea for showing that the number of multisets is \binom{n + r - 1}{n-1}
by translating every multiset to a standard subset of [n + r - 1] of size n-1 as follows:

(a) Suppose that we have  n = 5 elements and are interested in multisets of size r = 6.
Please describe what subset the multiset [1, 1, 2, 5, 5, 5] is translated to by Jakob's algorithm.

(b) Is Jakob correct? Can you prove that Jakob's algorithm gives a translation that shows that the number of multisets of size r from a universe of size n is \binom{n + r - 1}{n-1}? Or if there is an error in Jakob's algorithm, then what is it?

(c) Consider the original translation from multisets of size r from a universe of size n to subsets of size r from a universe of size n + r - 1 that we used in class, and that we proved to be correct.

For a fixed n and r, let us say that the Boolean predicate T_{n,r}(M,S) is true if the multiset M can be translated to the standard subset T by the method we studied in class and is false otherwise.

Indicate true/false:
- T_{n,r} describes a relation
- T_{n,r} describes a function
- T_{n,r} is surjective
- T_{n,r} is reflexive
- T_{n,r} is a partial order
- T_{n,r} is injective
- T_{n,r} is symmetric
- T_{n,r} is an equivalence relation
