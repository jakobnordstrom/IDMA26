6. TRICKY INDUCTION

(a) How many different tilings are there for a 2 \times 4 grid?

(b) How many different tilings are there for a 2 \times n grid? These are the Fibonacci numbers. Suppose that F(n) is the number of ways of tiling a 2-by-n grid. Then:
- If the rightmost tile is one vertical tile, we can tile the rest of the grid in F(n-1) ways.
- If the rightmost tiles are two horizontal tiles, we can tile the rest of the grid in F(n-2) ways.
- Hence, we get F(n) = F(n - 1) + F(n - 2).

8. TRICKY COMBINATORICS

Suppose that we have a universe of n elements and are interested in counting the number of multisets of size r.
Jakob has a new idea for showing that the number of multisets is \binom{n + r - 1}{n-1}
by translating every multiset to a standard subset of [n + r - 1] of size n-1 as follows:

(a) Suppose that we have  n = 5 elements and are interested in multisets of size r = 6.
Please describe what subset the multiset [1, 1, 2, 5, 5, 5] is translated to by Jakob's algorithm.

(b) Is Jakob correct? Can you prove that Jakob's algorithm gives a translation that shows that the number of multisets of size r from a universe of size n is \binom{n + r - 1}{n-1}? Or if there is an error in Jakob's algorithm, then what is it?

The algorithm should be correct. If we view the algorithm as marking boxes in a row of boxes of length n + r - 1, then the number of boxes before the first marked box is the number of copies of element 1 in the multi-set, the next interval identifies the number of copies of element 2, et cetera. If there are two marked boxes in a row, then there are no copies of the corresponding element in the multi-set. The number of unmarked boxes after the last marked box is the number of copies of the last element n in the multi-set.

(c) For the original original translation from multi-sets of size r from a universe of size n to subsets of size r from a universe of size n + r - 1, we have that:

- T_{n,r} describes a relation: Yes.
- T_{n,r} describes a function: Yes.
- T_{n,r} is surjective: Yes.
- T_{n,r} is reflexive: No (and this doesn't make sense anyway, since it is a relation between two different sets).
- T_{n,r} is a partial order: No (and this doesn't make sense anyway, since it is a relation between two different sets).
- T_{n,r} is injective: Yes.
- T_{n,r} is symmetric: No (and this doesn't make sense anyway, since it is a relation between two different sets).
- T_{n,r} is an equivalence relation: No (and this doesn't make sense anyway, since it is a relation between two different sets).
